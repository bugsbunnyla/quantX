\# QuantX



QuantX is a quantitative research and analytics platform designed to explore systematic trading concepts through an interactive dashboard experience.



The project serves as a practical learning environment for quantitative finance, data analysis, and strategy evaluation.



\---



\## Download



Clone the repository to your local machine:



```bash

git clone https://github.com/bugsbunnyla/quantX.git

```



Move into the project folder:



```bash

cd quantX

```



\---



\## Install Requirements



```bash

pip install -r requirements.txt

```



\---



\## Run QuantX

Start the application :
a.For Backtesting :

```bash
python -m qXengine.backtest.e2ebacktest



b. For production:
Ensure you have the config.py set for the URL access of at least two providers with api keys for access.
```bash

python main.py

```



\---



\## What Happens Next



QuantX will:



\* Load the configured data

\* Execute the enabled analytics and strategies

\* Generate results and visualizations

\* Open the QuantX Dashboard automatically in your browser
